## AdminAppService

Manages app definitions and installations. Every method requires a human
caller with server.manage and bot.create. Write methods also require the app
platform to be enabled.

<a id="chatto-admin-v1-AdminAppService-GetAppPlatform"></a>

### GetAppPlatform

Gets feature status and canonical app endpoints.

```http
POST /api/connect/chatto.admin.v1.AdminAppService/GetAppPlatform
```

<a id="chatto-admin-v1-GetAppPlatformRequest"></a>

#### Input: GetAppPlatformRequest

Reports whether app writes and compatibility routes are enabled.


<a id="chatto-admin-v1-GetAppPlatformResponse"></a>

#### Result: GetAppPlatformResponse

App platform status and canonical public endpoints.

| Field | Type | Description |
| --- | --- | --- |
| `enabled` | `bool` | Whether administrators can create or change apps. |

| `authorize_url` | `string` | Canonical browser authorization URL when enabled. |
